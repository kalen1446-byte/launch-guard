Safety layer for Meteora DBC

Know what a launch allows before you buy.

Every token on Meteora's Dynamic Bonding Curve is created from an on-chain config that decides what happens at graduation: who gets the liquidity, whether new tokens can be minted, whether a program runs on every transfer. Launch Guard reads that config and scores it.

Risk label of all launches

The risk is in the settings, not in DBC. The single largest config (175,599 launches) scores 0. A handful of launchpads ship 100% of their launches with mint authority or transfer hooks.

Mint authority options were allowed for every config up to program v0.1.x and restricted to transfer-hook configs in v0.2.0, so most of these launches are older. Full data and method: state-of-dbc-2026-10-07.json.

Under the hood

From a new pool to a score

No transaction parsing for discovery: every DBC pool stores its creation slot or time, so one filtered query returns only pools created in the last few minutes.

Find new poolsSolami getProgramAccountsV2, memcmp on activation_point (offset 296), every 15 s
Read the configPool → config account, decoded with the DBC IDL
Apply 8 rulesEach rule maps to a field and check in the DBC Rust source
Score 0–100Low, medium, high or critical, with a plain-English reason
DeliverDashboard stream, Telegram alerts and /check, JSON API

Open rules

What each flag means

Rules describe what a config allows. A high score is not a claim that a token is a scam. Read the rules and tests.

RuleFindingSeverityWhy it matters
R1Mint authority keptCriticalNew tokens can be minted and sold into the pool. Survives graduation.
R2Transfer hookCriticalA program runs on every transfer and can restrict selling while the token is on the curve.
R3Creator can withdraw LPHighUnlocked creator LP can be pulled right after graduation, leaving the pool thin.
R3bLaunchpad holds LPMediumUnlocked partner LP goes to the launchpad's fee claimer. Safe only if you trust it.
R4High or long feeHighBase fee stays high after the anti-sniper window; every trade pays it.
R5Large team allocationHigh20%+ of supply reserved for the creator, worse with a short cliff.
R6Large migration feeMediumRaised quote leaves at graduation instead of becoming liquidity.
R7Low graduation thresholdMediumUnder 10 SOL raised: post-migration liquidity is thin and easy to move.
R8Mutable metadataLowName, symbol and image can still change.

Who it is for

Traders, LPs and the launchpads themselves

Traders

Check a token before buying, from the dashboard or straight from a Telegram group.

Liquidity providers

DBC tokens migrate to DAMM v2. LPs there inherit the creator's unlocked LP and mint authority. Launch Guard shows how much of a pool can leave overnight.

Launchpads

Clean configs can prove it with a score. A config linter can catch risky settings before a config is created.

Terminals, bots and wallets

One API call adds a config-level risk signal that token scanners don't have.
